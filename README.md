# GRE 词汇系统

一个本地运行的 GRE 词汇记录工具，用 SQLite 保存数据，用 Streamlit 提供网页界面。当前版本只围绕 5 个词条字段工作：

- 英文单词
- 中文释义
- 词性
- 英文释义
- 词根

## 项目位置

项目目录：

`D:\AI培训工具\GRE_Vocabulary`

数据库：

`D:\AI培训工具\GRE_Vocabulary\gre_vocab.db`

## 启动

推荐直接双击：

```text
D:\AI培训工具\GRE_Vocabulary\启动网站.bat
```

也可以在命令行启动：

```powershell
cd "D:\AI培训工具\GRE_Vocabulary"
.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

启动后打开：

`http://127.0.0.1:8501`

## 页面

- `首页`：查看总词条数、今日计划复习量，并阅读使用教程。
- `新增单词`：单个录入或快速导入。
- `词库`：所有词条按英文首字母顺序排列；首字母索引会实时显示每个字母下的单词数量；可按关键词、词根索引和添加日期筛选；搜索时下方会显示同义索引下的完整词条。
- `同义词`：按归并后的中文含义自动分组，左侧是同义索引，右侧显示对应英文单词和原始中文释义。
- `同根词`：按提炼出的前缀 / 后缀 / 词根自动分组，左侧是词根索引，右侧显示对应单词，并支持手动重命名或合并索引。
- `复习`：设置复习天数，生成打乱均分的 Day 计划，进入当天列表和词卡，并更新熟悉度。
- `导出`：导出 Excel。

## 权限

本地默认是管理员模式。部署到公网时，建议配置管理员密码：

```toml
APP_ADMIN_PASSWORD = "换成你的管理员密码"
```

配置后，访客可以浏览词库、同义词、同根词和复习计划；新增、上传、编辑、删除、合并索引、生成复习计划和复习打分需要管理员登录。

## 快速导入格式

每行一个词条，字段顺序固定为：

```text
英文单词	中文释义	词性	英文释义	词根
abate	减弱；缓和	v.	to become less intense or widespread	bat/bate
laconic	简洁的；言简意赅的	adj.	using very few words	lac
```

推荐使用 Tab 分隔。系统也支持英文逗号分隔或竖线分隔：

```text
mitigate | 减弱；缓和 | v. | to make something less severe | mit/mis
```

如果同一个英文单词、中文释义和词性已经存在，快速导入会更新英文释义和词根，而不是重复新增。

## 同义词归类

同义词页不再按中文释义原文完全匹配。系统会为每个词条生成一个隐藏的“同义索引”，用来合并意思相近但写法不同的中文释义。

例如：

```text
abate    减弱；缓和
mitigate 减轻；缓解
```

这两个词会自动进入 `减弱/削弱/缓和` 这个同义索引。没有命中规则的词，会先使用中文释义里的第一个核心短语作为索引。

如果系统分得太细，可以在 `同义词` 页面打开 `调整同义索引`，把多个索引合并到当前索引；如果系统分得太粗，也可以重命名当前索引，再单独编辑词条中文释义。

## 同根词归类

同根词页也使用隐藏的“词根索引”，不再按原始词根字段完全匹配。系统会把相近写法提炼到同一个索引。

例如：

```text
abate    bat/bate
rebate   bate
```

会被归入 `bat/bate（减弱）`。如果系统没有命中内置规则，会优先使用你填写的词根片段作为索引。

如果词根索引分得太细，可以在 `同根词` 页面打开 `调整词根索引`，把多个索引合并到当前索引；也可以重命名当前索引。

## 导出内容

Excel 会生成在 `exports\` 目录，包含 4 个工作表：

- `01_单词库`
- `02_同义词`
- `03_同根词`
- `04_复习`
